# 搜图交互、标题翻译与孟加拉模式

日期：待确认。对应既有文档的 0.12.5—0.12.7 节点。

## 目标

让人工换图更可控，并为标题理解和高风险地区内容提供额外审核提示。

## 主要变更

- `assistant.js`、`background.js`：单按钮自适应搜图；默认由原标题生成英文视觉词，人工输入英文词可直接搜索但不覆盖持久化原标题搜图来源。
- `assistant.js`：优先使用 Chrome Translator API 显示原标题中文对照；手动触发时才使用付费 AI 翻译。
- `background-stock.js`、`background.js`、`assistant.js`：孟加拉语且国家为孟加拉时建议手动开启严格模式，对文案、图片元数据和结果状态追加人工审核约束。
- `workflow.js`：语言代码、翻译缓存及导入导出字段。
- `tests/tab-isolation-ui.mjs`、`tests/background-logic.mjs`：覆盖搜图、翻译和地区模式的模拟流程。

## 遇到的问题

- Chrome 离线翻译语言包的实际可用性因浏览器版本/语种而异，未逐语种真机验证。
- 图片自动初筛只依赖元数据和规则，无法替代投递前的人工视觉审核。
