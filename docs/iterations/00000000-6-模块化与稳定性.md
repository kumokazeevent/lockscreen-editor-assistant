# 模块化与稳定性

日期：待确认。对应既有文档的 0.13.0 节点。

## 目标

降低长批次处理时的界面跳动、重复挂载和下载/任务状态竞态，并分离可测试的辅助逻辑。

## 主要变更

- `background-entry.js`：改用 MV3 模块型 service worker 入口。
- `background-ai.js`、`background-stock.js`、`background-downloads.js`、`background-locks.js`：拆出错误分类、素材安全、下载命名及串行锁。
- `assistant-engine.js`、`assistant-ui.js`：进度摘要和局部卡片 DOM 更新；`assistant.js` 在收尾时再整体渲染。
- `tests/extension-load-smoke.mjs`、`tests/tab-isolation-ui.mjs`：验证 MV3 后台加载、局部 DOM 身份和多标签隔离。

## 遇到的问题

- 页面路由切换与悬浮窗异步挂载曾产生残留界面；当前有挂载修订号和节点清理，真实后台仍应回归测试。
- 浏览器关闭或重启会中断页面内运行的任务；旧批次可恢复，但未完成条目需要重试。
