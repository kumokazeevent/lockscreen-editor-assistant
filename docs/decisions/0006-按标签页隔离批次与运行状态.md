# ADR 0006：按标签页隔离批次与运行状态

状态：已实施；历史决策日期待确认。

## 上下文

用户需要同时打开多个后台页面并行处理，每个页面的批次、暂停、进度和编辑页匹配都不能相互干扰。

## 考虑的选项

1. 每标签页独立状态键、任务锁与恢复入口：符合多线并行使用；代价是要处理刷新、重启和旧批次归档。
2. 全浏览器共享一个当前批次：实现简单；但切换页面时容易覆盖或混合不同语言/国家结果。
3. 后台自动翻页合并一个大批次：减少手动切页；但与用户要“多个网站标签页互不干扰”的工作方式不符。

## 决策

以 `GET_TAB_CONTEXT` 的标签页上下文产生存储键；批次状态、设置、窗口和工作锁随标签页隔离。旧批次可归档后主动恢复；全局重复标记库和已完成图片用量保留跨标签页视图。

## 原因

`README.md` 明确记载多标签并行需求，代码中的标签页键与工作锁体现了隔离边界。把全局重复标记和用量作为例外可以防止不同批次重复选图；具体隔离键的历史演变原因待确认：由前代 Agent 决策。

## 影响

- 正面：A 页暂停、导入、清空不会直接改动 B 页；各页可独立设置并发。
- 负面：账户总并发可能叠加触发 API 限流；浏览器重启后的任务不自动继续，用户需恢复并重试。
