# ADR 0005：竖屏素材下载并保留人工上传

状态：已实施；历史决策日期待确认。

## 上下文

锁屏图需适合竖屏，偏好 9:16 或 9:20；素材可能有肖像、裸露、许可和后台上传格式问题。用户的最终工作流要求在后台手动上传图片并确认保存。

## 考虑的选项

1. Pexels 主源 + Pixabay 备选、下载后人工上传：候选丰富，筛选与最终决定分开；代价是仍有人工步骤及图库额度限制。
2. 自动将图直接写入后台上传控件并保存：步骤少；但后台上传状态、许可和审核风险更难确认，可能违背用户希望手动传图的流程。
3. 只提供搜图关键词：实现最轻；但仍需人工逐张下载、命名、格式转换。

## 决策

自动/手动搜图只接收竖向候选并优先接近目标比例；按来源和文件哈希去重，成品图下载到批次目录。AVIF/WebP/GIF 必要时转为 JPEG；标题/简介可在编辑页填写，图片上传和最终保存不自动执行。

## 原因

`README.md` 和代码明确将人工上传视为当前流程边界，并记录了 AVIF 无法上传的历史问题。Pexels/Pixabay 都有竖图参数和许可页，便于初筛；但元数据不能证明画面与授权完全合规，因此保留人工核验。选用这两个图库的原始商业/运营比较原因待确认：由前代 Agent 决策。

## 影响

- 正面：控制图片方向、格式、命名和重复率；人保留投递前最终判断。
- 负面：不是零人工操作；图片 API 故障或许可变化会影响流程，不能把“自动通过”解释为发布许可保证。
