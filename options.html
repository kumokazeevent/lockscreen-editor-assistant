文案规则

AI 标题翻译对齐与简介精简

AI 负责整句翻译原标题、生成中外词级对齐，并按原语言精简简介。未配置时只能使用本地简介精简，无法生成标题双语按钮；密钥仅保存在本机。

免费商用素材接口

Openverse 无需密钥。Pexels 和 Pixabay 需要各自的免费 API Key；三个来源都会在接口筛选后再次检查实际宽高，只显示竖图。申请 Pexels Key · 申请 Pixabay Key

已绑定网站

在网页悬浮窗点击“绑定字段”，依次绑定标题、简介和图片上传控件。

数据与隐私

标题、简介草稿和 API Key 只保存在本机浏览器中；站点绑定、接口地址和偏好保存在浏览器同步存储中。只有点击“翻译标题并精简简介”时稿件才会发送到你配置的 AI 接口；素材搜索词会发送给所选的 Openverse、Pexels 或 Pixabay。
