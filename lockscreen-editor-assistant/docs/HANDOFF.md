# 给下一位 Agent 的交接摘要

这是一个 Chrome/Edge Manifest V3 扩展项目，之前由 Codex 开发，现由你接手。

- 项目核心：辅助锁屏后台读取多语种原稿和正文、生成简介及由简介浓缩的标题、搜索竖屏图片，并在编辑页填写文案；图片上传与最终保存由用户手动完成。
- 主要技术栈：原生 JavaScript/HTML/CSS、模块型 service worker、Chrome 扩展 API、Node.js 测试、Playwright 模拟浏览器测试。当前版本 0.14.2，无构建步骤。
- 当前状态：六项静态、逻辑、MV3 加载与模拟界面测试在交接整理时通过；真实后台、真实 AI/图库 API 和下载上传链路还需现场验收。
- 已完成：多标签独立批次、30/40 条切换、词数限制、正文直读与兜底、独立 AI/可选审核、原标题搜图、竖屏图库、下载去重、JSON 导入导出、编辑页文案填入。
- 建议优先处理：先在真实后台验证 0.14.2 按 ID 捕获正文及错位页面，再用用户指定的真实 AI 端点/图库密钥验收一次完整流程；确认图片许可、安全及后台手动上传。

请先阅读项目根目录的 `AGENTS.md`，再看 `docs/iterations/` 最新记录与 `docs/decisions/`，运行 `AGENTS.md` 中的测试命令。任何不确定的历史动机或真实站点行为都向用户确认，不要把模拟测试当作线上验收。
