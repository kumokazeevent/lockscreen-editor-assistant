# 基础 MV3 扩展与后台适配

日期：待确认。此记录据当前代码回溯，无法确认各文件首次加入的精确版本。

## 目标

让助手在锁屏后台海外内容列表和编辑页出现，读取页面原稿并辅助填写文案。

## 主要变更

- `manifest.json`：限定内容脚本注入站点，声明 MV3、模块型后台、下载/存储/标签页权限和设置页。
- `content.js`、`content.css`：识别列表卡片与编辑路由，扫描标题、简介、链接和 ID，并定位标题/简介输入框。
- `assistant.js`、`assistant.css`：提供页面内悬浮窗与操作入口。
- `options.html`、`options.js`、`options.css`：设置页及站点字段绑定。

## 遇到的问题

- 后台卡片的“未投递”等状态文本可能与标题混淆；当前扫描逻辑用 `isCardMetaText` 排除。
- 后台 DOM/路由与字段选择器改变时适配会失效，需要在真实站点复核；历史修复日期待确认。
