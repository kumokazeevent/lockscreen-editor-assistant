# 竖屏图片与下载去重

日期：待确认。对应既有文档中的 0.11.1、0.12.0—0.12.3 等节点。

## 目标

提供可商用图库候选、竖图筛选、批量下载、可上传格式处理和跨批次重复提醒。

## 主要变更

- `background.js`、`background-stock.js`：Pexels 主源、Pixabay 备选、手动 Openverse 搜索；固定竖向参数并按比例/元数据排序初筛。
- `background.js`、`background-downloads.js`：优先 JPEG/PNG 下载；必要时将 AVIF/WebP/GIF 转为 JPEG 并同步扩展名；按 30/40 档分组命名。
- `workflow.js`：图片键、路径与批次命名、导入后的图片校验。
- `assistant.js`：候选图、重复标记、下载进度和人工复核状态。
- `tests/background-logic.mjs`、`tests/workflow-logic.mjs`：覆盖下载格式、重复与分组边界。

## 遇到的问题

- 曾有 AVIF 文件无法上传后台，以及“下载自动通过图”按钮无响应；既有文档记录修复，真实后台上传仍由用户操作并需复核。
- 图库元数据无法证明许可和画面安全；图库许可、肖像、商标与是否正脸均须人工核验。
