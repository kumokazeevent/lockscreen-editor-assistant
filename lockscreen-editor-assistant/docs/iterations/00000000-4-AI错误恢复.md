# AI 错误恢复

日期：待确认。对应既有文档的 0.12.4 节点。

## 目标

区分配置、鉴权、限流、服务端异常、空响应、截断与超时，并给用户可诊断、可重试的反馈。

## 主要变更

- `background.js`、`background-ai.js`：请求诊断、错误分类、退避重试、`Retry-After`、输出预算扩容，以及兼容 `max_completion_tokens` 的回退。
- `options.js`、`options.html`：主模型、可选备用模型、独立审核 AI、端点和超时设置。
- `assistant.js`：错误类型筛选、条目重试和进度提示。
- `tests/ai-recovery-logic.mjs`：覆盖分类、预算扩容、退避与备用模型条件。

## 遇到的问题

- 不同兼容服务商可能返回空正文、只含思考内容、404/401 或超时；自动重试无法修复错误端点或密钥。
- 模拟测试未用真实提供商制造 429/5xx；实际模型字段和限流策略待现场验证。
