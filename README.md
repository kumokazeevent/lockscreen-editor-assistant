# 锁屏编辑助手

一个不依赖后端服务的 Chrome / Edge 扩展 MVP，面向杂志锁屏内容审核与配图工作流。

## 已实现

- 标题默认最多 12 个字符、简介默认最多 50 个字符，超出后自动截断。
- 从当前网页或已绑定的后台字段读取标题与简介。
- 使用浏览器内置中文分词，在本地推荐图片搜索关键词。
- 一键打开百度图片、必应图片或 Google 图片搜索。
- 右键选中文字可直接搜图；右键图片可搜索相似图片或进入替换面板。
- 网页“换图模式”：点选图片、粘贴新图片 URL 或选择本地图片进行预览，并可撤销。
- 无需写 CSS：按页面提示点选标题、简介、图片 URL 输入框，即可绑定当前后台网站。
- 草稿只保存在本机，不会上传到外部服务。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹 `lockscreen-editor-assistant`。
5. 建议把“锁屏编辑助手”固定到浏览器工具栏。

修改代码后，在扩展管理页点击本扩展的“重新加载”即可生效。已经打开的后台网页也需要刷新一次。

## 第一次在内容后台使用

1. 打开内容编辑页面和扩展弹窗。
2. 点击“绑定后台字段”。
3. 按顶部绿色提示，依次点击标题输入框、简介输入框和图片 URL 输入框；如果后台没有图片 URL 输入框，可跳过第三步。
4. 此后在扩展中编辑文案，点击“填写到后台”即可。

## 换图说明

- 点击“进入换图模式”，再点击页面中要替换的图片。
- 可用关键词搜相关图、用 Google Lens 搜相似图、粘贴新图 URL 或选择本地图片。
- 如果绑定了图片 URL 字段，使用网络图片 URL 时会同步更新该字段。
- 扩展不会点击后台的“保存/提交”按钮，最终提交仍由编辑确认，避免误操作。

## 当前边界

- 某些后台把编辑器放在跨域 iframe 或 Shadow DOM 中，普通内容脚本无法直接绑定，需要为该后台单独适配。
- 本地图片只能在页面内预览；上传到后台仍需要使用后台自己的上传控件。
- 关键词推荐为本地规则算法，不调用大模型；优点是快且不泄露稿件，复杂标题的语义理解不如在线 AI。
