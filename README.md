# 锁屏编辑助手 0.4.2

面向杂志锁屏内容审核与配图工作的 Chrome / Edge 扩展。主界面是网页内常驻悬浮窗，不会像普通扩展弹窗那样在点击网页后自动消失。

## 主要功能

- 悬浮在网页内容最上层，可拖动、最小化，刷新和切换网页后自动恢复。
- 保留长原稿，点击“智能改写”后生成不超过 12 字的标题和不超过 50 字的简介。
- 自动识别原稿语言，标题和简介必须保持原语言、原文字系统，不再统一输出中文。
- 已针对越南语、西班牙语、俄语、英语、阿拉伯语以及中文加入语言识别与输出校验。
- 默认使用免费的本地编辑规则做完整词句精简，不是直接截取前 12/50 个字符。
- 可配置任意兼容 OpenAI Chat Completions 格式的接口，进行更自然的 AI 语义改写。
- 使用 GLM 5.x 时自动关闭深度思考，压缩提示词与输出范围，在优先保留主体、事件、结果和关键数字的前提下加快改写。
- 单独保留改写前的原标题和原简介，并据此生成适合 Pexels 的英文视觉关键词。
- 优先使用 Chrome 桌面版内置 Translator API 做免费本地中译英；不可用时回退到视觉词典或已配置的 AI 接口。
- 直接在悬浮窗搜索 Openverse 商业使用许可素材，无需 API Key。
- 可选接入 Pexels 免费 API，在悬浮窗搜索高质量竖图。
- Pexels 和 Openverse 均强制筛选竖向比例图片，适配手机锁屏版式。
- 素材卡片显示作者、来源和许可证，可一键把远程素材作为图片文件上传到后台。
- 可绑定内容后台的标题、简介和 `input[type=file]` 图片上传控件，实现一键填写与上传。
- 右键选中文字可直接搜图；右键图片可搜索相似图片或进入替换面板。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹 `lockscreen-editor-assistant`。
5. 建议把“锁屏编辑助手”固定到浏览器工具栏。
6. 已经打开的网页需要刷新一次，扩展才会注入悬浮窗。

修改代码后，在扩展管理页点击本扩展的“重新加载”，并刷新内容后台页面。

## 悬浮窗

- 安装并刷新普通网页后，悬浮窗默认显示。
- 拖动绿色标题栏可改变位置。
- 点击 `—` 最小化，点击工具栏扩展图标可显示或隐藏。
- 浏览器扩展只能置顶于网页内容之上，不能越过浏览器窗口置顶到 Word、微信等其他 Windows 软件上。

## 文案改写

1. 点击“重新读取页面”，或把原标题、原简介粘贴到悬浮窗。
2. 原稿允许暂时超过 12/50 字。
3. 点击“智能改写”。结果会再次进行字符数和完整词句校验。
4. 检查内容后点击“填写后台”。超限内容会被阻止，不会误填。

### 多语言规则

扩展先使用浏览器语言检测能力识别改写前的原标题和原简介，再把语言代码和语言名称传给 AI。AI 提示词明确要求：

- 标题和简介只能使用原稿语言；
- 保持原来的文字系统和自然拼写；
- 不得翻译成中文或其他语言；
- 只有 `image_query_en` 图片搜索词固定输出英文。

AI 返回后，扩展会再次检测标题和简介的语言。如果可靠检测结果与原稿不一致，会拒绝该结果并回退到保持原文语言的本地精简。

### 可选 AI 接口

在“设置 → AI 语义改写”中填写：

- Chat Completions 完整请求地址；
- 模型名称；
- API Key。

接口需要兼容常见的 `POST /v1/chat/completions` 请求和 `choices[0].message.content` 响应。API Key 只保存在浏览器本地；接口地址和模型名称保存在浏览器同步设置中。未配置或请求失败时，扩展会回退到本地智能精简。

当模型名称为 GLM 5.x（包括 `glm-5.2`）时，扩展会自动发送 `thinking: { type: "disabled" }`，并把输出限制在本任务所需的短 JSON 范围内。其他模型不会收到 GLM 专用参数，以保持接口兼容性。

## 商用素材

切换到“商用配图”后，点击“生成英文关键词”。扩展从改写前的原稿提取人物、地点、物体、场景和氛围词，而不是从已经缩短的 12/50 字成稿提取。点击搜索时，如果输入框仍是中文，也会先自动生成英文关键词。

### Openverse

无需密钥。扩展请求 `license_type=commercial` 并显示每张图片的具体 Creative Commons 或公共领域许可证。Openverse 聚合第三方站点的许可元数据，使用前仍应打开“查看来源”，核对署名、许可准确性、人物肖像和商标等权利。

### Pexels

1. 在 <https://www.pexels.com/api/> 免费申请 API Key。
2. 在扩展设置中填写并保存。
3. 在悬浮窗“商用配图”中选择 Pexels。

Pexels 图片允许免费商业使用，通常不强制署名，但插件仍显示摄影师与来源。不得把未修改图片作为图库、壁纸产品或原样商品重新销售，也要留意人物、品牌和商标权利。

## 第一次绑定内容后台

1. 打开内容编辑页面。
2. 在悬浮窗点击“绑定字段”。
3. 按网页顶部提示，依次点击标题输入框、简介输入框和图片上传按钮/选择文件区域。
4. 扩展会定位按钮关联的 `input[type=file]`；如果当前流程不需要图片上传，可跳过第三步。
5. 此后点击“填写后台”即可同步标题和简介。

## 图片上传

1. 在素材卡片点击“上传到后台”。
2. 扩展在后台请求素材文件，并在浏览器内存中生成带文件名和 MIME 类型的 `File`。
3. 文件会写入已绑定的后台上传控件，并触发 `input` 和 `change` 事件。
4. 检查后台显示的上传进度或图片预览，然后由编辑点击保存/提交。

这个过程等价于“下载图片到本地，再从文件选择器上传”，但中间文件无需落盘。原来的网页预览换图功能仍保留在右键图片菜单中，素材卡片的主操作已经改为真正上传。

扩展不会点击后台的“保存/提交”按钮，最终提交仍由编辑确认。

## 当前边界

- 某些后台把编辑器放在跨域 iframe 或封闭 Shadow DOM 中，需要针对该后台单独适配。
- 某些自研上传器不使用标准 `input[type=file]`，或需要先向服务器申请上传凭证；这类后台需要单独适配其上传流程。
- 自动写入文件会触发标准上传事件，但扩展不会点击最终保存/提交按钮。
- 本地智能精简主要做去冗余、关键句选择和完整词边界压缩；需要真正理解复杂新闻语义时，建议配置 AI 接口。
- 图片“允许商业使用”不等于没有任何限制，最终使用者仍需核对许可证、署名、肖像、隐私、商标和场景限制。
