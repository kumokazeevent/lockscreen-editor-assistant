# 锁屏编辑助手 0.7.5

面向杂志锁屏内容审核的 Chrome / Edge 扩展。它在指定后台页面显示常驻悬浮窗，批量读取文章、调用你自己的 AI 接口生成同语种文案、寻找竖屏商用图片，并在编辑页把文案和图片写入真实表单。

## 运行范围

扩展界面只注入：

- `https://lockscreen-admin.mofeeds.com/#/nav/overseasContent?index=5`
- `https://lockscreen-admin.mofeeds.com/#/nav/overseasDeliver?index=5&type=editEMPTY&id=...`

Chrome 的匹配规则不能直接限制 `#` 后的地址，所以清单先限制域名，再由扩展在运行时核对具体 hash 路由。其他页面不会显示悬浮窗。

## 这版能做什么

- 在列表页扫描当前已渲染卡片，按页面坐标从左到右、从上到下编号，单批最多 30 条。
- 标题扫描会排除卡片右上角的“未投递/已投递/审核中”等状态徽标，并降低右上角短文本和状态标签元素的候选权重。
- 每条内容分别显示“读取文章、AI 改写、搜索图片”的等待/进行中/完成/失败状态和本条百分比；顶部同时显示三个阶段的统计及整个批次总进度。
- 读取原标题和“查看链接”指向的文章内容；正文最多保留约 12,000 字符，避免本机存储过大。
- 独立 AI 接口一次返回标题、简介、英文图片搜索词和语言：
  - 标题不超过 12 个字符（空格和标点计入）；
  - 简介不超过 50 个字符；
  - 标题和简介必须与原标题语种一致；
  - 搜图词从原始标题和文章内容生成，而不是从改写结果反推；
  - 模型没有默认值，也不会纠正或替换名称；设置中输入什么模型 ID，请求就原样发送什么。DeepSeek 官方端点会明确关闭深度思考。默认并发 2；超时立即返回，429/5xx 或格式错误最多重试 2 次。
- Pexels 优先、Pixabay 备用；只保留实际高度大于宽度的图片，并优先接近 9:16 或 9:20。
- 搜索词和本地规则会尽量避开清晰正脸、大面积皮肤裸露等风险；无法确定的图片会标记为“需人工复核”，不会伪装成已通过。
- 原稿/批次 JSON 与重命名后的图片保存到两个独立子目录。
- 编辑页从批次记录匹配当前内容 ID，填写标题与简介，并通过真实 `<input type="file">` 写入图片文件。
- 不自动点击后台最终“保存/提交”，必须人工确认预览和内容后再保存。

## 安装与更新

首次安装：

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 始终选择固定目录 `lockscreen-editor-assistant`。
5. 打开扩展设置，填写独立 AI、Pexels（可再填 Pixabay）密钥。

以后更新不要卸载扩展：直接替换固定目录内文件，在扩展管理页点击“重新加载”，再刷新后台页面。这样扩展 ID、本机 API Key、字段绑定和批次状态都会保留。

## 接口设置

设置页默认预填：

- Chat Completions 地址：`https://api.deepseek.com/chat/completions`
- 模型：不预填；必须填写购买接口时提供商给出的准确模型 ID，插件不会改名
- 超时：30 秒
- 并发：2

设置页会分别列出 AI、Pexels 和备用 Pixabay 的接口地址与 API Key。请填写你自己的密钥。AI 接口需兼容 OpenAI Chat Completions 请求；插件可读取 `choices[0].message.content`、`output_text` 或 Responses 风格的 `output`。此处使用的是独立 API 额度，不会读取 ChatGPT Plus 登录状态。

密钥保存在 `chrome.storage.local`，不会写入扩展源码或打包文件。

## 批处理流程

1. 在列表页打开悬浮窗，点击“扫描当前列表”。
2. 核对条数、编号顺序和原始标题；如果“查看链接”或编辑链接没有识别出来，先不要开始。
3. 点击“开始处理”。可以暂停，失败项目可单独重试；刷新页面后会从本机批次状态恢复。
4. 检查每条生成文案、图片来源、尺寸、比例和安全标记。
5. 下载原稿/批次记录和所选成品图。
6. 打开对应编辑页，点击“填入文案并上传图片”。确认后台已经出现上传预览后，再手工点击保存。

## 下载目录与文件名

设置中的目录是相对于浏览器“下载”目录的子目录，默认：

- 原内容：`锁屏批次/原始内容`
- 成品图片：`锁屏批次/成品图片`

浏览器扩展不能静默写入任意绝对路径。文件名格式类似：

`01-标题【简介】_9x16.jpg`

Windows 文件名不能包含 `////`，因此界面可继续展示 `标题////简介`，磁盘文件改用合法分隔符。

## 第一次字段绑定

编辑页会先自动识别标题、简介和文件上传控件。识别失败时，在悬浮窗启动字段绑定，按提示依次点击：

1. 标题输入框；
2. 简介输入框；
3. 图片的真实文件上传控件或其上传区域。

绑定保存在本机设置中。后台页面如果改版，可删除旧绑定后重新绑定。

## 常见问题

- `Endpoint is unavailable`：提供商对应模型端点暂时不可用，核对完整地址、模型 ID 和账户额度；扩展不会用本地精简悄悄替代失败结果。
- AI 返回内容为空：0.7.5 会停止无意义的连续重试，并显示返回模型、choices 数量、finish_reason、思考内容长度和顶层字段，便于判断提供商实际采用的响应格式。
- OpenCode 返回 404 网页：Go 接口必须填写 `https://opencode.ai/zen/go/v1/chat/completions`，模型填写正式 ID `deepseek-v4-flash`。0.7.1 会自动纠正 `dsv4flash` 等简称，并在首次致命接口错误后停止剩余批次。
- `signal is aborted without reason` 或“超过 30 秒”：通常是请求超过设置超时、页面/扩展刚重载或上游主动断开。0.7.1 起超时只请求一次，避免同一条连续等待约 90 秒；可稍后点击重试，确实经常在 30–60 秒返回时再调高超时。
- 提示语言不一致：返回结果没有通过原标题语种校验，扩展会重试，仍失败则保留原稿等待人工处理。
- 扫描为 0 条：确认路由正确并等列表加载完成；当前实现不会为了识别链接而主动点击页面按钮。
- 图片已写入但后台无预览：说明页面不是标准文件控件或站点上传组件已变更，需要重新绑定/适配；没有预览时不要保存。

## 边界与人工复核

- 悬浮窗置顶范围是当前网页，不能覆盖其他 Windows 软件窗口。
- Pexels/Pixabay 的“可商用”条件仍可能涉及署名、人物肖像、隐私、商标和敏感场景，发布前必须打开来源页核对。
- 浏览器内的关键词和轻量安全检查不能可靠判断所有正脸、裸露或图片语义。标记为“通过”也应快速目视复核。
- 由于后台实际 DOM 需要登录才能查看，本版提供多级自动识别与诊断；若站点结构与截图不同，第一次可能需要手动绑定字段。
