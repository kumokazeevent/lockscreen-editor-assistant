# 锁屏编辑助手 0.5.3

面向杂志锁屏内容审核与配图工作的 Chrome / Edge 扩展。主界面是网页内常驻悬浮窗，点击网页后不会像普通扩展弹窗一样消失。

## 本版功能

- 自动读取内容后台的原标题和原简介。
- AI 将标题改写为不超过 12 个字符、简介改写为不超过 50 个字符；空格和标点也计入字符数。
- 标题在保持原意的前提下优先增强趣味性和吸引力，并保留人物、地名、专业术语等重要专有名词。
- 专有名词本身超限时，优先使用通用公认缩写或昵称；没有合适缩写时只保留名词核心。
- 自动识别原标题语言，越南语、西班牙语、阿拉伯语、俄语、白俄罗斯语、英语和中文均保持原语言与原文字系统。
- GLM 5.x（包括 `glm-5.2`）会自动关闭深度思考，以较低温度和短输出优先保证速度与准确性。
- 读取原标题后，自动把原标题总结为 5–8 个英文视觉关键词并立即搜索图片，无需再点击生成或搜索。
- Openverse、Pexels、Pixabay 三个素材源均在接口参数和实际宽高两层筛选，只显示 `height > width` 的竖图。
- 素材卡只提供图片预览、来源页面和署名信息，不下载图片，也不向内容后台上传图片。
- 标题和简介字段可以一次绑定，检查文案后可一键填写后台。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹 `lockscreen-editor-assistant`。
5. 已经打开的内容后台页面需要刷新一次。

修改代码后，在扩展管理页点击本扩展的“重新加载”，再刷新内容后台页面。

## 文案改写

1. 点击“重新读取页面”，或把原标题、原简介粘贴到悬浮窗。
2. 点击“智能改写”。
3. 插件会验证标题不超过 12 个字符、简介不超过 50 个字符，并检测结果是否保持原标题语言。
4. 检查后点击“填写后台”。超限内容会被阻止。

AI 标题提示词的核心规则为：保持原意、趣味性优先、保留重要专有名词、输出语言与原标题一致。插件接口需要同时接收标题和简介，因此模型返回严格 JSON；悬浮窗的标题框只显示缩简后的标题，不显示 Markdown 代码块、引号或解释。

简介继续使用原有智能精简逻辑，优先保留主体、行动、结果和关键事实，不做机械截断。

### AI 接口

在“设置 → AI 语义改写”填写：

- Chat Completions 完整请求地址；
- 模型名称；
- API Key。

接口应兼容 `POST /v1/chat/completions` 和 `choices[0].message.content`。API Key 只保存在浏览器本地。未配置、请求失败、返回语言错误或标题超限时，扩展会回退到本地精简。

在线文案改写最多等待 45 秒；原标题生成图片关键词最多等待 30 秒。超时提示会说明上游服务或网络较慢，不再直接显示 `signal is aborted without reason`。

## 自动搜索竖图

页面原文读取完成后，扩展只使用改写前的原标题生成英文视觉关键词，并立即使用当前素材源搜索。手动点击“重新搜索原标题”可以再次生成和搜索；切换素材源也会自动重搜。

所有语言都优先使用已配置的 AI 生成精确英文关键词。AI 失败或未配置时，英文原标题直接提取关键词；其他语言回退到 Chrome 本地 Translator API，再回退到内置视觉词典。

### Openverse

无需密钥。请求固定使用 `license_type=commercial`、`aspect_ratio=tall` 和安全内容过滤，结果再按实际宽高检查。使用前仍应打开来源页核对具体许可、署名、肖像和商标权利。

### Pexels

在 <https://www.pexels.com/api/> 申请免费 API Key，然后在扩展设置中保存。请求固定使用 `orientation=portrait`，结果再按实际宽高检查。

### Pixabay

在 <https://pixabay.com/api/docs/> 获取免费 API Key，然后在扩展设置中保存。请求固定使用 `image_type=photo`、`orientation=vertical` 和 `safesearch=true`，结果再按实际宽高检查。搜索结果按关键词和页码在本机缓存 24 小时，以减少免费 API 额度消耗。

## 第一次绑定后台文案字段

1. 打开内容编辑页面。
2. 在悬浮窗点击“绑定字段”。
3. 按网页顶部提示，依次点击标题输入框和简介输入框。
4. 此后点击“填写后台”即可同步标题和简介。

## 当前边界

- 悬浮窗只置顶于当前网页内容之上，不能跨越浏览器窗口置顶到其他 Windows 软件上。
- 某些后台把编辑器放在跨域 iframe 或封闭 Shadow DOM 中，需要针对该后台单独适配。
- 本地精简适合应急回退；复杂多语言语义和专有名词缩写建议使用已配置的 AI 接口。
- “允许商业使用”不等于没有任何限制，最终使用者仍需核对许可证、署名、肖像、隐私、商标和场景限制。
