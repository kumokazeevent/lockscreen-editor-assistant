# 锁屏编辑助手 0.12.1

用于锁屏后台的 Chrome / Edge 扩展：读取原稿、同语种改写、搜索竖屏图片，在编辑页填写标题和简介。图片由你手动上传，后台最终保存也由你确认。

## 0.12.1 自动下载按钮修复

- 修复“下载自动通过图”错误依赖整条记录完成状态的问题。现在只要图片本身为“自动筛选通过”，即使文案仍需复核也可以下载。
- 有批次但没有自动通过图时，按钮仍可点击，并明确显示已选图片与需复核图片数量。
- 下载按钮显示可下载数量；下载期间显示逐张进度，结束时显示成功、重复跳过、失败数量及首个错误。

## 0.12.0 界面与下载优化

- 列表页先显示批处理操作，“当前文件夹”和“当前标签页设置”移动到处理区域下面。
- 编辑页先显示“从批次填入当前编辑页”，文件夹和标签页设置移到该功能下面。
- “批次记录”“当前文件夹”“当前标签页设置”均可折叠；没有批次时记录列表默认收起，有记录时默认展开。
- 批量图片下载从 2 路提升为最多 4 路并发；同一批次的下载目标在开始时固定，下载途中切换文件夹不会写错目录。

## 0.11.1 图片格式修复

- 修复素材服务器根据浏览器请求返回 AVIF，导致后台无法上传的问题。
- 图片请求现在优先 JPEG；如果服务端仍返回 AVIF、WebP 或 GIF，插件会解码并以 94% 品质重新编码为 JPEG，文件后缀与实际内容保持一致。
- 原本就是 JPEG 或 PNG 的图片不会重复压缩；PNG 保留透明通道。
- 如果浏览器太旧而不支持转换，会明确报错，不会继续保存一个不可上传的 AVIF 文件。

## 本次调整

- 修复导入 / 读取不断追加记录的问题：旧批次归档，界面只展示选中的文件夹。旧版混合多页 JSON 会按页面与语言国家拆分，重复导入不再叠加。
- 文件夹名称采用“语言_国家_读取时间”（含毫秒和防重后缀）。列表页从后台筛选框读取语言和国家；识别不到显示“未知”，可在顶部手动补全，不猜测国家。时间是读取时间，不是投递日期。
- 顶部增加 30 / 40 条切换，控制单次读取上限与图片分组大小。网站必须已经显示足够条数；选择 40 不会自动翻页，也不会凭空补足缺少的记录。切换档位不会删除已有记录。
- 原稿 JSON、结果 JSON 和成品图都在各自根目录下使用相同的语言国家时间子目录。
- 多页面处理改为多个浏览器标签页独立运行，不自动翻后台列表页，也不把其他标签页合并到当前批次。
- 每个标签页分别保存批次、进度、暂停状态、词数设置、改写模式、思考强度、窗口状态和图片重复记录。多个标签页可以同时处理。
- 标题和简介改为按词计数，默认标题最多 12 词、简介最多 50 词。标题可调 1–100 词，简介可调 1–500 词。
- AI 提示词、重试校验、本地改写、JSON 导入、界面计数和后台填写使用相同词数规则。
- 原有 API 配置不会被清空。旧批次保留在本机，可主动恢复到当前标签页。

## 更新安装

已经安装时不要卸载：

1. 将新版文件放入原来加载扩展的固定目录。
2. 打开 chrome://extensions（Edge 使用 edge://extensions），点击本扩展的“重新加载”。
3. 刷新所有已经打开的后台标签页，避免旧脚本继续运行。

保持原加载目录、不卸载扩展，才能继续使用原扩展 ID 和本机设置。首次安装时开启“开发者模式”，选择“加载已解压的扩展程序”，选中包含 manifest.json 的目录。

## 多标签页并行使用

1. 在浏览器分别打开多个后台列表标签页，每页自行选择需要处理的列表和筛选条件。
2. 在每个标签页顶部选择 30 或 40 条，点击“读取当前页”，核对语言、国家、原稿与条数。
3. 分别点击“开始处理”，各标签页会独立运行。A 页暂停或清空批次，不会暂停或清空 B 页。
4. 同一个标签页进入某条记录的编辑页时，会按内容 ID 匹配该标签页的批次结果。
5. 点击填写标题和简介，手动上传图片，核对后在后台保存。

新打开的标签页不会自动继承另一页的结果。需要转移或切换结果时，展开“切换文件夹 / 恢复旧版批次”，点击“刷新文件夹列表”，选择后点“打开选中文件夹”；也可导入结果 JSON。当前旧批次先归档，打开操作不删除来源批次。

导入含多个页面的旧 JSON 时，默认打开第一组；如果正在编辑页，则优先打开包含当前内容 ID 的组，其余保存在文件夹列表。缺少语言、国家的旧 JSON 不能可靠恢复完整筛选条件，请在打开后手动补全并点击“保存语言国家”。名称修改只影响之后的下载，不会移动已经下载的文件。

同一标签页刷新后可以恢复自己的批次。浏览器重启后使用新的隔离标识；之前的批次仍可通过上述恢复入口找回。进行中的请求不会在关闭页面后继续由该页面处理，恢复后可重试未完成记录。

每个标签页的并发设置只控制该页；例如两页各设并发 2，总计可能同时发出 4 个请求。API 账户仍然共用提供商额度和限流。

## 词数规则与设置

例如 `How to care for cats` 计为 5 词，不是按字母数量计数。

- 空格、独立标点和表情不计词数；数字计一个词。
- 单词内部的撇号和连字符视为同一个词，例如 don't 和 well-known 各计 1 词。
- 英语、西班牙语、俄语、阿拉伯语等按书写词单元计数。
- 越南语按空格分隔的书写单元计数，多音节词可能计作多个单元。
- 中文等无空格文本使用浏览器分词能力，不按每个字符计算。

在悬浮窗展开“当前标签页设置 · 词数 / 模式 / 思考强度”，可修改该页词数上限、AI / 本地模式及思考强度。这里的修改不会改变其他标签页。

独立设置页中的词数、模式和并发是新标签页的默认值；已有标签页保留自己的选择。API 地址、密钥、模型和自定义提示词等通用配置仍共享。

设置页可以修改简写提示词，支持 `{titleLimit}`、`{summaryLimit}` 占位符。工具会补充词数、语言和输出格式要求；旧提示词中的常见“字符限制”表述会转换为“词数限制”。复杂的自定义提示词建议自行检查。

纯本地模式不调用主 AI 或审核 AI，也不使用 AI 翻译搜图关键词；生成内容需要人工复核。AI 模式使用你填写的模型 ID，不自动替换模型名称。可选审核 AI，默认不要求启用。

## 图片与下载

- 保留 Pexels 主图源和 Pixabay 备选，只接受竖向图片，优先接近 9:16 或 9:20。
- 图片搜索支持上一页 / 下一页；这是搜图结果翻页，不是后台内容列表自动翻页。
- 从原始标题和文章内容生成英文搜图词，优先使用原图地址。编辑页可自动读取原稿并搜图，也可在设置关闭自动搜图。
- 支持素材 ID、地址和文件 SHA-256 重复检查，以及手动标记重复、取消标记、明确选择仍然下载。
- 重复历史按标签页隔离，不会因为 A 页下载而阻止 B 页下载。这不是视觉相似识别，也不扫描电脑已有文件。
- 搜索规则会尽量降低正脸、过量皮肤裸露等风险，但仍需要人工看图审核。

默认下载子目录为 `锁屏批次/原始内容` 和 `锁屏批次/成品图片`。两者下面按批次增加例如 `俄语_白俄罗斯_20260905-143025123-abc123` 的独立目录。时间精确到毫秒，末尾短标识用于避免同时读取时重名。

成品图按选择的 30 / 40 档位分组：30 档为 `第001组_001-030`、`第002组_031-060`；40 档为 `第001组_001-040`、`第002组_041-080`。两个档位分别计数，切换不会移动旧文件。重复跳过的图片不占组内编号。图片文件名包含编号、标题和简介，并替换 Windows 不允许的文件名字符。

目录相对于浏览器下载位置，扩展不能静默写入任意绝对路径。下载图片后，请在后台上传控件手动选择文件。

## JSON 保存和恢复

- “保存批次 JSON”保留已完成、待处理和失败记录。
- 支持导出已完成页面及导入结果 JSON；旧批次含多个页面时仍可按页面筛选。
- 导入文件内部按内容 ID 去重，在当前标签页的词数上限下重新校验，并检查图片方向与编辑链接；不向现有批次追加。语言、国家、读取时间及 30 / 40 档位随新版 JSON 保存和恢复。
- 新版导出标明 `countUnit: words`；兼容旧版结果 JSON，纯原始内容 JSON 不当作改写结果。
- “导出并新建批次”先导出，再清空当前标签页批次，不影响其他标签页。
- JSON 不包含 API 密钥；单文件上限 32MB，较大的历史批次可分页面导出。

## 后台适配和人工确认

界面在 lockscreen-admin.mofeeds.com 的海外内容列表和相应编辑路由显示。卡片扫描会排除“未投递”等状态徽标。标题、简介输入框识别失败时，可使用重新绑定字段功能。

助手只填写标题、简介，不上传图片，不自动点击后台最终保存。浮窗只在当前网页范围置顶，不能覆盖其他 Windows 软件窗口。

接口超时、模型输出为空、语言不一致或词数超限会显示诊断，不能将失败当作已完成。图片许可、肖像和商标等风险也须在发布前核对来源页。
