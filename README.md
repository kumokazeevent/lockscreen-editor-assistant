# 锁屏编辑助手 0.6.1

面向杂志锁屏内容审核与配图工作的 Chrome / Edge 扩展。主界面是网页内常驻悬浮窗，点击网页后不会像普通扩展弹窗一样消失。

## 本版功能

- 自动读取内容后台的原标题和原简介，并以 `标题////简介` 显示在同一个原稿框中。
- 新增待填写文案框：第一行自动识别为标题，换行后的内容自动识别为简介。
- 页面原稿栏提供快捷复制按钮。
- 可拖动悬浮窗右下角调整界面大小，位置与尺寸会自动保存。
- 填写后台前检查标题和简介的字符上限；空格和标点也计入字符数。
- 读取原标题后，自动把原标题总结为 5–8 个英文视觉关键词并立即搜索图片，无需再点击生成或搜索。
- Openverse、Pexels、Pixabay 三个素材源均在接口参数和实际宽高两层筛选，只显示 `height > width` 的竖图。
- 素材卡提供图片预览与一键下载，图片保存到浏览器下载目录下的“锁屏素材”文件夹。
- 标题和简介字段可以一次绑定，检查文案后可一键填写后台。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹 `lockscreen-editor-assistant`。
5. 已经打开的内容后台页面需要刷新一次。

修改代码后，在扩展管理页点击本扩展的“重新加载”，再刷新内容后台页面。

## 文案填写

1. 点击“重新读取页面”，原稿框会显示 `标题////简介`。
2. 在“待填写文案”框中输入标题，换行后输入简介。
3. 点击“填写后台”，插件会自动拆分第一行标题和后续简介并写入已绑定字段。
4. 标题或简介超出设置中的字符上限时，填写会被阻止。

### AI 图片关键词接口

在“设置 → AI 图片关键词”填写：

- Chat Completions 完整请求地址；
- 模型名称；
- API Key。

接口应兼容 `POST /v1/chat/completions` 和 `choices[0].message.content`。API Key 只保存在浏览器本地。原标题生成图片关键词最多等待 30 秒；未配置或请求失败时会回退到本地关键词生成。

## 自动搜索竖图

页面原文读取完成后，扩展只使用读取到的原标题生成英文视觉关键词，并立即使用当前素材源搜索。手动点击“重新搜索原标题”可以再次生成和搜索；切换素材源也会自动重搜。

所有语言都优先使用已配置的 AI 生成精确英文关键词。AI 失败或未配置时，英文原标题直接提取关键词；其他语言回退到 Chrome 本地 Translator API，再回退到内置视觉词典。

### Openverse

无需密钥。请求固定使用 `license_type=commercial`、`aspect_ratio=tall` 和安全内容过滤，结果再按实际宽高检查。使用前仍应打开来源页核对具体许可、署名、肖像和商标权利。

### Pexels

在 <https://www.pexels.com/api/> 申请免费 API Key，然后在扩展设置中保存。请求固定使用 `orientation=portrait`，结果再按实际宽高检查。

### Pixabay

在 <https://pixabay.com/api/docs/> 获取免费 API Key，然后在扩展设置中保存。请求固定使用 `image_type=photo`、`orientation=vertical` 和 `safesearch=true`，结果再按实际宽高检查。搜索结果按关键词和页码在本机缓存 24 小时，以减少免费 API 额度消耗。

## 第一次绑定后台文案字段

1. 打开内容编辑页面。
2. 在悬浮窗点击“绑定字段”。
3. 按网页顶部提示，依次点击标题输入框和简介输入框。
4. 此后点击“填写后台”即可同步标题和简介。

## 当前边界

- 悬浮窗只置顶于当前网页内容之上，不能跨越浏览器窗口置顶到其他 Windows 软件上。
- 某些后台把编辑器放在跨域 iframe 或封闭 Shadow DOM 中，需要针对该后台单独适配。
- 非英文原标题在浏览器不支持本地翻译时，会回退到内置视觉词典生成图片关键词。
- “允许商业使用”不等于没有任何限制，最终使用者仍需核对许可证、署名、肖像、隐私、商标和场景限制。
