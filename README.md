# 锁屏编辑助手 0.9.0

面向杂志锁屏内容审核的 Chrome / Edge 扩展。它在指定后台页面显示常驻悬浮窗，批量读取文章、调用你自己的 AI 接口生成同语种文案、寻找竖屏商用图片，并在编辑页把标题和简介写入表单。图片由人工上传。

## 运行范围

扩展界面只注入：

- `https://lockscreen-admin.mofeeds.com/#/nav/overseasContent?index=5`
- `https://lockscreen-admin.mofeeds.com/#/nav/overseasDeliver?index=5&type=editEMPTY&id=...`

Chrome 的匹配规则不能直接限制 `#` 后的地址，所以清单先限制域名，再由扩展在运行时核对具体 hash 路由。其他页面不会显示悬浮窗。

## 这版能做什么

- 多页读取：从当前列表连续翻页，或并行读取已打开的多个后台标签页（列表页及编辑页）。每次读取 / 处理页数可选 1–20，每页最多 30 条，一个批次最多保存 600 条；相同内容 ID 合并。
- 每轮按页数设置处理前 N 个待处理页；可先用“显示页面”筛选指定页面。未轮到的记录保持待处理，下次继续。
- 已完成页面可单独导出 JSON，也可一键导出所有已完成页面；“保存批次 JSON”保留失败和待处理记录。导入时按 ID 合并并校验文案字数、图片竖向尺寸和编辑地址，编辑页自动匹配。
- 可选择 AI 改写或本地词语候选。纯本地模式完全不调用 AI，不翻译图片搜索词；结果标记为需人工复核，可到“手动填写”编辑后录入。
- 标题上限可调 1–100 字符，简介 1–500 字符，默认 12 / 50。界面、AI 校验与表单写入统一以 NFC 规范化后的 Unicode 码点计数（包括空格和标点）。
- 悬浮窗默认加宽，并根据可用窗口宽高调整；仍可拖动、缩放和最小化。
- 标题扫描会排除卡片右上角的“未投递/已投递/审核中”等状态徽标，并降低右上角短文本和状态标签元素的候选权重。
- 每条内容分别显示“读取文章、AI 改写、搜索图片”的等待/进行中/完成/失败状态和本条百分比；顶部同时显示三个阶段的统计及整个批次总进度。
- 读取原标题和“查看链接”指向的文章内容；正文最多保留约 12,000 字符，避免本机存储过大。
- 独立 AI 接口一次返回标题、简介、英文图片搜索词和语言：
  - 标题不超过 12 个字符（空格和标点计入）；
  - 简介不超过 50 个字符；
  - 标题和简介必须与原标题语种一致；
  - 搜图词从原始标题和文章内容生成，而不是从改写结果反推；
  - 模型没有默认值，也不会纠正或替换名称；输入什么模型 ID，请求就原样发送什么。思考可选关闭、低、中等、高、最高或跟随提供商；DeepSeek / GLM 使用对应请求参数，未识别的模型保留提供商默认行为。默认并发 2；超时立即返回，429/5xx 或格式错误最多重试 2 次。
  - 中等思考与最终正文共享输出预算：首次提供 4096 tokens；仅当模型因思考占满预算且 `finish_reason=length` 时，自动提高到 8192 tokens 重试。普通空响应不会盲目重试。
  - 提示词要求 AI 在输出前逐字符复核；若一次结果仍超限，下一次请求会带上上一次的具体失败原因，而不是原样重复请求。
  - 可选第二套审核 AI；审核 AI 使用快速无思考模式。审核接口失败且主结果已通过本地校验时，保留主结果并标记“审核跳过”；主结果不合格时不会绕过校验。本地模式不会调用主 AI 或审核 AI。
  - 简写提示词可在设置页编辑、保存和恢复默认；支持 `{titleLimit}` / `{summaryLimit}` 占位符。工具补充必需的字数、语言、配图词与 JSON 输出格式要求。
- Pexels 优先、Pixabay 备用；只保留实际高度大于宽度的图片，并优先接近 9:16 或 9:20。
- 配图结果支持上一页 / 下一页；翻页沿用英文关键词及素材源。批次卡片“换图 / 翻页”可选择新图片写回该条结果。
- 进入编辑页自动读取原始标题与简介，并生成英文关键词搜索；已有批次关键词直接复用。可在设置关闭自动搜图，也可手工输入英文关键词直接搜索。
- 下载前检查素材 ID / 地址和 SHA-256 文件内容，相同文件即使换地址或并发下载也会跳过；支持手动标记重复、取消标记，以及明确选择“仍然下载”。这是相同素材 / 文件去重，不是视觉相似图识别，也不会扫描电脑已有图片目录。记录从 0.9.0 开始积累。
- 搜索词和本地规则会尽量避开清晰正脸、大面积皮肤裸露等风险；无法确定的图片会标记为“需人工复核”，不会伪装成已通过。
- 原稿/批次 JSON 与重命名后的图片保存到两个独立子目录。成品图按累计下载顺序每 30 张自动新建一组目录。
- 编辑页从批次记录匹配当前内容 ID，只填写标题与简介；图片保留为人工上传。
- 编辑页记录选择器使用自定义列表显示“编号-处理状态”；失败状态红色加粗，点击记录立即跳转到对应编辑页。
- 编辑页与列表页切换使用挂载序号锁；并发路由事件只允许最后一次挂载生效，同时清除遗留的悬浮窗，页面始终只保留一个助手窗口。
- 不自动点击后台最终“保存/提交”，必须人工确认预览和内容后再保存。

## 安装与更新

首次安装：

1. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 始终选择固定目录 `lockscreen-editor-assistant`。
5. 打开扩展设置，填写独立 AI、Pexels（可再填 Pixabay）密钥。

以后更新不要卸载扩展：直接替换固定目录内文件，在扩展管理页点击“重新加载”，再刷新后台页面。这样扩展 ID、本机 API Key、字段绑定和批次状态都会保留。

## 接口设置

设置页默认预填：

- Chat Completions 地址：`https://api.deepseek.com/chat/completions`
- 模型：不预填；必须填写购买接口时提供商给出的准确模型 ID，插件不会改名
- 超时：30 秒
- 并发：2

设置页会分别列出 AI、Pexels 和备用 Pixabay 的接口地址与 API Key。请填写你自己的密钥。AI 接口需兼容 OpenAI Chat Completions 请求；插件可读取 `choices[0].message.content`、`output_text` 或 Responses 风格的 `output`。此处使用的是独立 API 额度，不会读取 ChatGPT Plus 登录状态。

密钥保存在 `chrome.storage.local`，不会写入扩展源码或打包文件。

## 批处理流程

1. 在列表页选择读取来源及页数，点击“读取并合并页面”。连续翻页从当前页开始并停留在最后读到的页面；多标签方式优先读取当前标签，然后按标签排列顺序读取。
2. 核对条数、编号顺序和原始标题；如果“查看链接”或编辑链接没有识别出来，先不要开始。
3. 点击“开始处理”。可暂停，失败项目可单独重试；完成的文案可点击“按新设置重写”。刷新或关闭处理标签后，本机保留已完成记录；占用锁最多 30 秒到期后可以继续。多个标签不会同时改写同一批次。
4. 检查每条生成文案、图片来源、尺寸、比例和安全标记。
5. 下载原稿/批次记录和所选成品图。
6. 打开对应编辑页，点击“填入标题和简介”，再手工上传对应图片；核对完成后点击后台保存。
7. 下次可在任一助手页面导入结果 JSON，自动恢复并匹配；“导出并新建批次”先导出当前结果，再清空本机当前批次。0.8.0 的批次结果 JSON 也支持导入，纯原始内容 JSON 不当成改写结果。

## 下载目录与文件名

设置中的目录是相对于浏览器“下载”目录的子目录，默认：

- 原内容：`锁屏批次/原始内容`
- 成品图片：`锁屏批次/成品图片`

浏览器扩展不能静默写入任意绝对路径。文件名格式类似：

`01-标题【简介】_9x16.jpg`

成品图会按累计下载数量自动放入分组目录：第 1–30 张进入 `第001组_001-030`，第 31–60 张进入 `第002组_031-060`，刷新或重新加载扩展后仍会接着计数。更换“成品图片目录”后，新目录会单独开始计数。

Windows 文件名不能包含 `////`，因此界面可继续展示 `标题////简介`，磁盘文件改用合法分隔符。

重复图片在分组计数前跳过；浏览器中断的下载可以重试。JSON 最大 32MB，超过时按页面分别导出。为存储多页原稿，本版使用 `unlimitedStorage` 扩展本机存储权限；长提示词和密钥仅存本机，结果 JSON 不含 API Key。

## 第一次字段绑定

编辑页会先自动识别标题和简介输入框。识别失败时，在悬浮窗启动字段绑定，按提示依次点击：

1. 标题输入框；
2. 简介输入框。

绑定保存在本机设置中。后台页面如果改版，可删除旧绑定后重新绑定。

## 常见问题

- `Endpoint is unavailable`：提供商对应模型端点暂时不可用，核对完整地址、模型 ID 和账户额度；扩展不会用本地精简悄悄替代失败结果。
- AI 返回内容为空：0.7.5 会停止无意义的连续重试，并显示返回模型、choices 数量、finish_reason、思考内容长度和顶层字段，便于判断提供商实际采用的响应格式。
- OpenCode 返回 404 网页：核对购买产品对应的完整接口地址与正式模型 ID；插件不再纠正模型简称。
- `signal is aborted without reason` 或“超过 30 秒”：通常是请求超过设置超时、页面/扩展刚重载或上游主动断开。0.7.1 起超时只请求一次，避免同一条连续等待约 90 秒；可稍后点击重试，确实经常在 30–60 秒返回时再调高超时。
- 提示语言不一致：返回结果没有通过原标题语种校验，扩展会重试，仍失败则保留原稿等待人工处理。
- 扫描为 0 条：确认路由正确并等列表加载完成；当前实现不会为了识别链接而主动点击页面按钮。
- 编辑页不会自动上传图片；请下载成品图后在后台手动选择对应文件上传。

## 边界与人工复核

- 悬浮窗置顶范围是当前网页，不能覆盖其他 Windows 软件窗口。
- Pexels/Pixabay 的“可商用”条件仍可能涉及署名、人物肖像、隐私、商标和敏感场景，发布前必须打开来源页核对。
- 浏览器内的关键词和轻量安全检查不能可靠判断所有正脸、裸露或图片语义。标记为“通过”也应快速目视复核。
- 由于后台实际 DOM 需要登录才能查看，本版提供多级自动识别与诊断；若站点结构与截图不同，第一次可能需要手动绑定字段。
